# bmo-push

Simple BMO-style git push helper.

## Usage

```bash
chmod +x bmo
./bmo                  # commits with "bmo save"
./bmo "your message"   # custom commit message
```

Works anywhere normal `git` works (iSH, laptop, NUC, etc.).

On iSH after pushing from another machine:

```bash
git pull
```
